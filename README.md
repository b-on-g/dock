# $bog_dock

Панель приложений, наследник `$giper_web_bar`. Встраивается в любое приложение через iframe и не добавляет Базу в его бандл.

```tree
<= Dock $bog_dock_frame
	query <= query
```

`query` подставляется в адреса приложений вместо `{query}`.

- `bog/dock/bar` панель
- `bog/dock/frame` встраивание
- `bog/dock/demo` демка
- `bog/dock/app` страница: внутри iframe панель, сама по себе карта приложений и их связей
- `bog/dock/card` карточка любого объекта Базы по ссылке, без класса приложения
- `bog/dock/card/app` создание открытого объекта и его карточка
- `bog/dock/side` панель слева в готовом приложении: `include \/bog/dock/side` в `meta.tree` и второй корень `<div mol_view_root="$bog_dock_side"></div>` в `index.html` после корня приложения. На узком экране язычок у левого края (тап или свайп), внутри iframe и в попапе ничего.
